# Siyadumisa Khuzwayo — Portfolio & CV Website

A responsive, high-craft developer CV portfolio website for **Siyadumisa Khuzwayo**, built with a bespoke Royal Blue tech theme, interactive binary stream background, and structured showcases of software development projects, database competencies, and workplace productivity tools.

---

## 🚀 Key Highlights

- **Bespoke Royal Blue Theme & Ambient Canvas**: Custom royal blue styling with an interactive HTML5 Canvas streaming binary code (`0` and `1`) with smooth 60fps performance and accessibility motion checks.
- **Office Productivity Suite Showcase**: Detailed proficiencies in **Microsoft Word** (technical documentation & specifications), **Microsoft Excel** (formulas, data analysis, spreadsheets), and **Microsoft PowerPoint** (stakeholder presentations & architecture walk-throughs).
- **Databases & Data Management**: Practical foundation in relational database schema design, normalization, SQL querying, and session state persistence.
- **Programming Stack**: Modern semantic **HTML5 & CSS3**, **Python** (OOP, logic & data structures), software quality assurance, and Git version control.
- **Featured Project — Tutorverse (Lesson Session Platform)**:
  - Real-time video learning platform for educators and students (comparable to Zoom or Microsoft Teams).
  - Integrated Jitsi Meet engine for dynamic room creation.
  - REST API contracts (`POST /sessions`, `GET /sessions/{id}`) and persistent database session logging.
  - **Live Proof**: [https://lesson-session-platform.vercel.app](https://lesson-session-platform.vercel.app)
  - **Source Code**: [https://github.com/siyadumisakhuzwayo-code/lesson-session-platform](https://github.com/siyadumisakhuzwayo-code/lesson-session-platform)
- **Direct Curriculum Vitae Link**: Direct access and download for [`cv.pdf`](./cv.pdf).
